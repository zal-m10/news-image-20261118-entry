# news-image-20261118-entry

**Sum up 18 November 2026 world news in one image** — make.fun competition entry.

## Competition
- **Bounty:** [news-image-20261118](https://make.fun/bounty/news-image-20261118)
- **Prize pool:** $250 (1st: $50, 2nd: $30, 3rd: $15, 4-10th: $5, 11-50th: $3)
- **Deadline:** 2026-11-20T00:00:00Z

## Entry
This program writes a front-page style image summarizing the world's news of Wednesday, 18 November 2026 to `/output/entry.png`.

| Region | Stories |
|--------|---------|
| **Americas** | Trump in Manila (ASEAN/APEC Summit), APEC Shenzhen (Xi hosts Trump, Putin) |
